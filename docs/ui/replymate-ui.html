03

主链路 · 4 步，全程 ≤ 300ms 唤起

A 路径不降级完成的占比目标是 ≥80%；任何一步失败都必须一步滑到 B，不允许"你自己想办法"。

STEP 01
点悬浮球
前台包白名单校验 → 2s 内读一屏可见消息
→
STEP 02
判角色 + 带出档案
双信号投票定"对方 / 我"，自动带上次关系与目标
→
STEP 03
流式出 3 条
首字 ≤2.5s，3 条可点 ≤6s，整批原子不混排
→
STEP 04
回填，人工发送
L1 SET_TEXT → L2 粘贴 → L3 复制，永不代发
不可退的三条：永不自动发送 ／ 离线模板必打「离线模板 · 未调用模型」角标（中性灰） ／ 一批 3 条只能是全模型或全模板，禁止混批。
